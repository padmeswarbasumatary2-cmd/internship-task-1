📋 AVAILABLE ENDPOINTS (8 TOTAL)

Tagging Operations:
  1. POST /api/v1/tag-content
     └─ Main tagging endpoint
     └─ Input: title, content
     └─ Output: categories, tags, entities with scores

  2. POST /api/v1/batch-tag
     └─ Process multiple documents
     └─ Input: array of content objects
     └─ Output: array of tagging results

Taxonomy Management:
  3. GET /api/v1/categories
     └─ List all available categories
     └─ Returns: hierarchical category list

  4. GET /api/v1/taxonomy
     └─ Export full taxonomy graph
     └─ Returns: JSON-formatted taxonomy structure

  5. POST /api/v1/resolve-entity
     └─ Normalize entities to canonical form
     └─ Input: entity text
     └─ Output: canonical form with confidence

Feedback & Learning:
  6. POST /api/v1/validate-tags
     └─ Submit editorial feedback
     └─ Input: accepted/rejected/manual tags
     └─ Purpose: Active learning

System Information:
  7. GET /api/v1/health
     └─ System health status
     └─ Returns: status, version, connectivity info

  8. GET /api/v1/model-info
     └─ Model and configuration information
     └─ Returns: loaded models, parameters, capabilities
